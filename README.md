# My Maintenance Planner

A lightweight, phone-friendly home and property maintenance planner.

## Version 1 features

- Overdue, due-soon, upcoming, and completed dashboard
- Home, HVAC, vehicle/UTV, lawn/outdoor, and property categories
- Add, edit, delete, search, and filter maintenance tasks
- Recurring intervals with automatic next-due calculation when a task is completed
- Track equipment/area, mileage or hours, cost, parts/supplies, and notes
- Stores data locally in the browser
- Progressive Web App manifest and basic offline cache

## Run locally

Open `index.html` in a browser. For full PWA/offline behavior, serve the folder over HTTP (for example with a simple local web server) or enable GitHub Pages.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
